# 📱 TechNews Today - Desafio 10 

Este repositório contém a entrega do **Desafio 10**, referente à atividade proposta no curso de **Desenvolvimento de Sistema** pelo **SENAI**. 

O projeto consiste em uma página web estática para um portal de notícias de tecnologia ("TechNews Today"), desenvolvida para demonstrar a aplicação prática de marcação semântica e técnicas modernas de estilização visual.

## 🚀 Tecnologias Utilizadas

*   **HTML5:** Estrutura semântica da página (`<header>`, `<main>`, `<article>`, `<section>`, `<form>`, etc.).
*   **CSS3:** Estilização avançada, incluindo CSS Grid, flexibilidade, gradientes e responsividade.

## ✨ Funcionalidades e Aprendizados Aplicados

Durante o desenvolvimento deste projeto, os seguintes conceitos foram aplicados:

*   **Glassmorphism:** Efeito visual de vidro fosco aplicado no cabeçalho usando `backdrop-filter`.
*   **CSS Grid Layout:** Estruturação do layout principal para ser responsivo, adaptando-se a telas maiores (colunas divididas na proporção 2:1).
*   **Tags Interativas:** Uso das tags `<details>` e `<summary>` para criar conteúdo expansível (Leia mais) sem necessidade de JavaScript.
*   **Formulários:** Criação de uma seção de Newsletter com campos de texto, caixa de seleção (`<select>`) e checkbox (`<input type="checkbox">`).
*   **Mídia Incorporada:** Inserção de vídeos do YouTube utilizando a tag `<iframe>`.
*   **Estilização de Texto:** Uso de `-webkit-background-clip` para criar textos com gradiente (na logo).

## 📁 Estrutura de Arquivos

*   `desafio10.html`: Arquivo principal contendo a estrutura da página.
*   `desafio10.css`: Arquivo de folhas de estilo contendo todo o design e responsividade.

## 🛠️ Como Executar o Projeto

1. Faça o clone deste repositório em sua máquina local:
   ```bash
   git clone https://github.com/Mariabrito09/Technews-today.git
   ```
2. Navegue até a pasta do projeto.
3. Abra o arquivo `desafio10.html` em qualquer navegador web (Chrome, Firefox, Edge, etc.). Nenhuma instalação de dependências ou servidor local é necessária.
